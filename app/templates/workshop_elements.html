Element Library

Reference catalog for all workflow element types in the QMS Workflow Engine. Each demo is fully interactive — interact with the element to see the state JSON update live.

text

leaf element

A free-form string input. Renders with a current-value display, text input, and Set button. Press Enter or click Set to commit.

Live demo
State JSON

      
YAML definition

      
fields:
  title:
    label: Title
    type: text
    instruction: Provide a short, descriptive title.

    

  

  
Notes:
    
    
      
  • Supports default, visible_when, side_effects
    • 
      
  • Legacy alias: none (text was always "text")
    • 
    

  







  
toggle
leaf element

  
A boolean yes/no element. Always renders as a Yes/No button pair — never a dropdown. The active choice is highlighted.

  

    

      
Live demo

      

        
      

      

    

    

      
State JSON

      

      
YAML definition

      
affects_code:
  label: Code Impact
  type: toggle    # legacy: boolean
  instruction: Does this change affect code?

    

  

  
Notes:
    
    
      
  • Value is true or false (not strings)
    • 
      
  • Commonly paired with side_effects to reveal other elements on change
    • 
      
  • Legacy alias: type: boolean
    • 
    

  







  
choice
leaf element

  
A selection from a fixed option set. Renders as buttons (≤3 short options) or a dropdown (>3 options, or any option longer than 20 characters).

  

    

      
Live demo — button group (3 options)

      

        
      

      

      
Live demo — dropdown (6 options)

      

        
      

      

    

    

      
State JSON

      

      
State JSON

      

      
YAML definition

      
priority:
  label: Priority
  type: choice    # legacy: select
  instruction: Select the urgency level.
  options: [Low, Medium, High]

category:
  label: Category
  type: choice
  instruction: Select the change category.
  options_from: change_categories  # top-level set

    

  

  
Notes:
    
    
      
  • Button vs dropdown threshold: >3 options, or any option >20 chars
    • 
      
  • options: inline list; options_from: reference to top-level option_sets
    • 
      
  • dynamic_options: options derived from another field's current value
    • 
      
  • annotate_from + annotation: visually mark a subset of options
    • 
      
  • Legacy alias: type: select
    • 
    

  







  
indicator
leaf element

  
A read-only computed value. No affordance — agents cannot set it. The instruction switches between instruction_when_true and instruction_when_false based on the computed value.

  

    

      
Live demo

      

        
        
      

      

    

    

      
State JSON

      

      
YAML definition

      
readiness_check:
  label: Readiness Check
  type: indicator   # legacy: computed
  compute:
    fn: all_set
    args: [title, category, priority]
  instruction_when_true: All required fields are set.
  instruction_when_false: Please complete all required fields.

    

  

  
Notes:
    
    
      
  • No affordance is emitted — this element is always read-only
    • 
      
  • Instruction switches based on current computed value
    • 
      
  • Commonly used as a proceed gate prerequisite check
    • 
      
  • Supported compute.fn values: all_set, any_set, equals, not_equals
    • 
      
  • Legacy alias: type: computed
    • 
    

  







  
group
container element

  
A named collection of fields that share a single affordance. One POST sets all fields at once. Fill any combination of fields and click Set All to commit.

  

    

      
Live demo

      

        
      

      

    

    

      
State JSON

      

      
YAML definition

      
fields:
  title:
    label: Title
    type: text
    instruction: Short, descriptive title.
  affects_code:
    label: Code Impact
    type: toggle
    instruction: Does this change affect code?
  purpose:
    label: Purpose
    type: text
    instruction: Why is this change needed?

field_groups:
  initiation:
    label: Basic Information
    instruction: |
      Provide the core identifying information.
      All fields are required before you can proceed.
    fields: [title, affects_code, purpose]

    

  

  
Notes:
    
    
      
  • Group instruction is required — validated at load time
    • 
      
  • Fields listed under field_groups.fields must be declared in fields
    • 
      
  • Rendering order follows the YAML definition order of the fields list
    • 
      
  • A single "Set All" button covers all fields — you can fill any subset
    • 
    

  







  
table
structural element

  
A structured data grid with typed columns. Supports add row operations. Click "Add row" to append a new empty row.

  

    

      
Live demo

      

        
      

      

    

    

      
State JSON

      

      
YAML definition

      
table:
  column_type_catalog: test_result
  properties:
    min_rows: 1
  operations: [add, edit, remove]

# Top-level column type catalog:
column_types:
  test_result:
    type: choice
    choices: [Pass, Fail, N/A]

    

  

  
Notes:
    
    
      
  • Distinct from execution_table — free-form data, not a plan
    • 
      
  • column_type_catalog references a top-level column_types entry
    • 
      
  • operations: add, edit, remove, reorder
    • 
    

  







  
list
structural element

  
An ordered collection of structured items. Each item conforms to an item_schema. Add items with the form below; click Remove to delete.

  

    

      
Live demo

      

        
      

      

    

    

      
State JSON

      

      
YAML definition

      
lists:
  items:
    label: Action Items
    item_schema:
      name:
        type: text
        required: true
      status:
        type: choice
        options: [Open, In Progress, Done]
    operations: [add, remove]
    focus: false

    

  

  
Notes:
    
    
      
  • Item schema field types: text, toggle, choice
    • 
      
  • required: true fields must be set before an item can be saved
    • 
      
  • focus: true enables item-scoped rendering — selecting an item restricts visible state to that item's fields
    • 
      
  • Operations default to all four if not specified
    •
