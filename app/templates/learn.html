Learning Portal

A guided tour of Razem, one lesson at a time.

These lessons walk through how the engine works from the ground up — building a first component, tracing a request through the core loop, composing pages, and seeing why the same URL serves humans and AI agents identically. Start at Lesson 1 if you’re new.

Before you start

  • You can run the engine locally with python run.py — the lessons reference live demo pages you can click through while reading.
  • Each lesson is ~5 minutes of reading plus optional hands-on time. Lessons build on each other; read in order the first time.
  • This is the gentle introduction. For the deep theory see /framing; for the full reference see /readme; for an interactive tour of every component type see the Agent Portal (launch a Component Gallery instance).
